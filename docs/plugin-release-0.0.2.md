# 主仓插件 0.0.2 · 统一图标批次

本批同步主应用仓库的 19 个插件，包版本统一保持 `0.0.2`，最低宿主为 Moki `0.0.5`。index 自有的 OpenAI 兼容 OCR、TypeSafe 兼容 JEV 保持 `0.0.1`／最低宿主 `0.0.1`。App 保持 `0.0.6`／build 6，本次不发布 App。

## 内容与兼容性

- 19 个插件接入[统一图标规范](plugin-icons.md)：细线、统一尺寸、列表蓝青双色、工具栏文字色和宿主圆背景，每插件共用一份 PNG。
- AI 回复原文可全文编辑，包括归属标记，生成消费修改后的正文。完整编辑体验需配套本轮 Moki `0.0.6`；插件清单最低宿主仍为 `0.0.5`。
- 保留采集版的节点＋OCR、统一清洗和失败处理：宿主执行 OCR 计划并校验证据；AI 回复遇到混合采集失败提示重试，会话管理不重复截图并保留手填入口。飞书对方消息归属仍待双方真实会话验证。
- SDK 保持 `1.0.0`，`ui.read`、`ocr.postprocess`、`chat.profile`、`knowledge.query` 接口主版本保持 `1`。App 版本、插件包版本、规则版本、SDK 和接口主版本分别管理，仅在用户明确要求时调整 App／插件版本。

## 下载与同版本覆盖

[本批独立预发布](https://github.com/JamesGZM/moki-index/releases/tag/plugins-icons-0.0.2-20261022) 包含 19 个 `.mopk` 与 `SHA256SUMS`。单包的下载地址、SHA256、字节数见[当前索引](../plugins/v2/index.yaml)；版本与展示大小见 [README](../README.md) 的插件表。

按用户要求，本批继续使用 `0.0.2`，而旧采集版已有四个同版本包。为保持下载内容可追溯，新内容使用独立 Release tag `plugins-icons-0.0.2-20261022`，不覆盖 `plugins-capture-0.0.2` 下的旧附件。旧四条目的完整记录保存于[采集版快照](../archives/plugins-capture-0.0.2.yaml)，所有 `0.0.1` 下载记录继续保留。

已安装旧 `0.0.2` 的用户不会因为包内容变化收到版本更新提示；需要从本批 Release 下载 `.mopk`，在插件管理中导入覆盖。**不要为刷新图标卸载插件或清除数据。** Release tag 用来区分附件批次，不作为 manifest 的插件版本。预发布附件与索引合并分别管理，只有 PR 合入 `main` 后线上索引才会切换。
