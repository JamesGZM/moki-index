# 插件图标规范 1.0

2026-10-22 固定。主仓 19 个插件及本仓 JEV／OCR 两个插件均采用这套规范；每个插件只维护一份 SVG 母版和一份运行时 PNG，列表和工具栏共用同一图形。

## 几何与颜色

| 参数 | 规范 |
| --- | --- |
| 设计画布 | 24×24 单位，透明背景 |
| 可见范围 | 主体约 18×18，通常位于 x/y=3..21；允许最多 0.5 单位光学校正 |
| 线条 | 1.5 单位，圆端点、圆连接；不使用实心 AI 星芒或淡底填色 |
| 负空间 | 关键间隙至少 2 单位，18dp 下仍能辨认主体 |
| 列表颜色 | 品牌蓝 `#0066FF`，青色 `#20B8E9` 点缀 |
| 运行资源 | 256×256 透明 PNG；不烘焙圆背景、状态标记或功能名称 |

AI 回复、写作、帮写共享线框四角星芒，主体分别为回复气泡、纸笔、文字与光标。知识库用书本与索引页签，会话用人物与资料卡。同步系列共用双向箭头，以云、存储桶、电脑与手机区分服务；备份使用单向上传与存档盒。三种语音图形表达功能，不作为服务商官方 Logo。表情插件只更换入口图标，不更改表情内容。

## 宿主主题与清单

本仓两项补充：TypeSafe 兼容 JEV 用判断菱形及分支结果；OpenAI 兼容 OCR 用扫描角框与文字 A，不与带勾的 OCR 清洗图标混淆。母版为 [JEV](plugin-icons/typesafe-jev.svg)／[OCR](plugin-icons/openai-ocr.svg)，各插件 `resources/icon-v1.png` 为运行资源；两个插件版本升级到 0.0.2，功能／配置和最低宿主保持。发布状态见[记录](jev-ocr-icons-0.0.2.md)。

```json
{
  "icon": "icon-v2.png",
  "iconThemed": true,
  "minHostVersion": "0.0.5"
}
```

图片位于包内 `resources/`。首批 AI 回复、AI 写作、AI 帮写、翻译、知识库、会话使用 `icon-v2.png`；另外 13 个使用 `icon-v1.png`。示例展示图标本身的最低要求；AI 回复还依赖原文全文编辑，实际 `minHostVersion` 必须为 `0.0.6`。`iconThemed` 是包内 manifest 的显示声明，索引中的 `icon` 与包内资源名保持一致。

商店列表与详情不预先下载插件包，图片条目另外提供 `iconUrl`。主应用仓库为私有仓库，不能使用它的匿名 raw 地址；本批将包内同一份 PNG 保存到公开 index 仓库的 `plugins/v2/icons/<id>/<PNG的SHA256>.png`，使用本仓 main 的公开 HTTPS raw 地址。摘要路径随图片内容变化，旧图保留，避免同版本修订命中旧缓存；这是资源发布副本，不是重新设计的第二套图形。

`icon` 继续表示清单中的字符或文件名，不能把文件名当文字画出来，也不能当远程图片地址使用。App 两处共用图片渲染，保留 PNG 原色及透明背景；加载中／失败时使用分类图标，旧文字图标仍可直接显示。该字段是索引的可选扩展，不调整任何版本号或最低宿主声明；旧 App 需要包含商店图片支持的同版本构建才能显示。图片请求直接访问公开 raw，现有仅代理 YAML 的 Worker 无需修改或重新部署。

- 列表显示 PNG 原色；工具栏将同一 PNG 的透明轮廓按键盘 `keyTextColor` 着色，随深浅模式和自定义主题变化。
- 插件条目背景由宿主统一使用主题 `primaryContainer`，文字／分类回退使用 `onPrimaryContainer`，不再按插件类别使用不同深浅底色；深色主题随主题变化。PNG 不烘焙背景，成功加载后不叠加分类图形。
- 主工具栏图像框 22dp、圆背景 32dp；定制预览图像框 18dp、圆背景 28dp。圆背景由宿主提供，与最左侧入口协调。
- 不为列表与工具栏分别导出两套 PNG，不因换图新增插件入口。知识库仍没有工具栏入口。
- 未声明 `iconThemed` 的存量图片保留原色。资源更新使用新的文件名避开旧图片缓存；包版本与资源文件名分别管理。

## 审核要求

同时检查 18dp／22dp 的混排效果，至少涵盖插件与剪贴板、表情、语音、文字识别；覆盖浅色、深色、非蓝主题和图片背景。比较整排的线宽、大小、视觉中心及负空间，同时检查禁用、选择、加载失败和冷启动／热重载。九键、26 键、窄宽度及横向滚动均需检查，不能以放大原图或浏览器 CSS 像素代替手机验收。
