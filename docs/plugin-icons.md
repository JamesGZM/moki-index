# 插件图标规范 1.0

2026-10-22 固定。本批主仓 19 个插件均采用这套规范；每个插件只维护一份 SVG 母版和一份运行时 PNG，列表和工具栏共用同一图形。

## 几何与颜色

| 参数 | 规范 |
| --- | --- |
| 设计画布 | 24×24 单位，透明背景 |
| 可见范围 | 主体约 18×18，通常位于 x/y=3..21；允许最多 0.5 单位光学校正 |
| 线条 | 1.5 单位，圆端点、圆连接；不使用实心 AI 星芒或淡底填色 |
| 负空间 | 关键间隙至少 2 单位，18dp 下仍能辨认主体 |
| 列表颜色 | 品牌蓝 `#0066FF`，青色 `#20B8E9` 点缀 |
| 运行资源 | 256×256 透明 PNG；不烘焙圆背景、状态标记或功能名称 |

AI 回复、写作、帮写共享线框四角星芒，主体分别为回复气泡、纸笔、文字与光标。知识库用书本与索引页签，会话用人物与资料卡。同步系列共用双向箭头，以云、存储桶、电脑与手机区分服务；备份使用单向上传与存档盒。三种语音图形表达功能，不作为服务商官方 Logo。表情插件只更换入口图标，不更改表情内容。

## 宿主主题与清单

```json
{
  "icon": "icon-v2.png",
  "iconThemed": true,
  "minHostVersion": "0.0.5"
}
```

图片位于包内 `resources/`。首批 AI 回复、AI 写作、AI 帮写、翻译、知识库、会话使用 `icon-v2.png`；另外 13 个使用 `icon-v1.png`。`iconThemed` 是包内 manifest 的显示声明，索引中的 `icon` 与包内资源名保持一致。

- 列表显示 PNG 原色；工具栏将同一 PNG 的透明轮廓按键盘 `keyTextColor` 着色，随深浅模式和自定义主题变化。
- 主工具栏图像框 22dp、圆背景 32dp；定制预览图像框 18dp、圆背景 28dp。圆背景由宿主提供，与最左侧入口协调。
- 不为列表与工具栏分别导出两套 PNG，不因换图新增插件入口。知识库仍没有工具栏入口。
- 未声明 `iconThemed` 的存量图片保留原色。资源更新使用新的文件名避开旧图片缓存；包版本与资源文件名分别管理。

## 审核要求

同时检查 18dp／22dp 的混排效果，至少涵盖插件与剪贴板、表情、语音、文字识别；覆盖浅色、深色、非蓝主题和图片背景。比较整排的线宽、大小、视觉中心及负空间，同时检查禁用、选择、加载失败和冷启动／热重载。九键、26 键、窄宽度及横向滚动均需检查，不能以放大原图或浏览器 CSS 像素代替手机验收。
